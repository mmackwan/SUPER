# Super Forecast

## Publish on GitHub Pages

1. Unzip the download.
2. Create a GitHub repository named `super-forecast`.
3. Upload `index.html`, `apple-touch-icon.png`, and `favicon.png` together to the repository root and commit them. The included `.nojekyll` file is optional and tells GitHub to serve the files directly. The README can also be uploaded.
4. In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and click **Save**.
5. Once published, use **Settings → Pages → Visit site** to find your link. Open that link in Safari on your iPhone or iPad and choose **Share → Add to Home Screen**. On a Mac, choose **File → Add to Dock** in Safari.

The calculator is self-contained in `index.html`. Its example uses Russell iQ Super – Employer GoalTracker. Choose your matching fee schedule and enter any insurance or other account-specific charges. Saved forecasts stay in the browser where you saved them and do not sync across devices. The ZIP contains example figures only.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
